# v2.5.0 workflow engine transition

Starting with **v2.5.0**, new workflow runs use Appsmith's native engine.

Workflows that started before v2.5.0 continue on **Temporal**. Every **v2.5.x** release still runs Temporal so those runs can finish.

**v2.6** removes Temporal. Stay on a v2.5.x release and finish this checkpoint before you upgrade to v2.6.

This applies to self-hosted instances. Appsmith Cloud does not use these checkpoints.

## While you are on v2.5.x

Sign in as an instance administrator, open **Admin Settings**, and under **Instance** select **Admin central**.

The checkpoint is **v2.5.0 · Workflow Engine Transition**. **Learn more** on that row opens this page. For how checkpoints work in general, use **How checkpoints work** on the same screen, or see [Upgrade checkpoints](/getting-started/setup/instance-management/upgrade-checkpoints).

While Temporal runs are still open, Admin central marks the upgrade as blocked. It lists each workflow, the workspace it belongs to, how many runs are still open, and the age of the oldest run.

<ZoomImage
  src="/img/checkpoint-v2.5.0-pending.png"
  alt="Admin central showing the v2.5.0 Workflow Engine Transition checkpoint with open Temporal runs and Upgrade blocked"
  caption="Open Temporal runs block the upgrade to v2.6"
/>

Let an open run finish when you can. Stop a run only if you mean to end that work.

While runs are still open, the action on the page is **Skip checkpoint...**. Read the confirmation before you skip. Skipping records that you chose to move on with those runs unfinished. Later upgrades will not ask about this checkpoint again.

When no runs are still open, **Skip checkpoint...** is replaced by **Acknowledge**. Acknowledge records the checkpoint as finished.

## After you acknowledge

Admin central moves the checkpoint to **Collected**. The record shows the version, the name **Workflow Engine Transition**, the outcome **Marked complete**, and who finished it and when.

<ZoomImage
  src="/img/checkpoint-v2.5.0-collected.png"
  alt="Admin central Collected list with the v2.5.0 Workflow Engine Transition checkpoint marked complete"
  caption="A finished checkpoint no longer blocks the next upgrade"
/>

Under **Pending**, Admin central shows **No checkpoint pending. Nothing blocks your next upgrade.** You can then upgrade to v2.6.

## If the server does not start

This happens when the instance was moved to v2.6 or later before this checkpoint was finished. Appsmith stops the backend before it comes up, so Admin central is not available.

Follow [Upgrade checkpoints](/getting-started/setup/instance-management/upgrade-checkpoints#if-the-server-does-not-start). Return to the v2.5.x version named in the log, finish or skip this checkpoint in Admin central, then upgrade again.
