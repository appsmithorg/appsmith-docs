# Upgrade Appsmith Versions

This page explains how to update your self-hosted Appsmith instance to the latest version.

## Prerequisites

Before you update, make sure that:

1. You have at least 2 GB of free storage for the backup and update.
2. Your embedded or external MongoDB server runs version 5.0 or later. To upgrade MongoDB, check the [supported platforms](https://www.mongodb.com/docs/manual/administration/production-notes/#platform-support) and follow the [MongoDB replica set upgrade guide](https://www.mongodb.com/docs/manual/release-notes/5.0-upgrade-replica-set/).
3. You have a backup of your Appsmith instance. To create one, follow the [Backup instance guide](/getting-started/setup/instance-management/appsmithctl/#backup-instance).

## Update Appsmith

Select your platform and follow the steps to update Appsmith to the latest version:

<Tabs queryString="current-platform-type">

<TabItem label="Docker" value="docker">

These instructions apply to Docker-based platforms, such as Docker standalone and AWS AMI.

:::caution Important
Some versions are checkpoints that you must install before you upgrade further:
 - If your current version is earlier than v1.9.2, follow the [Upgrade to Checkpoint Version (v1.9.2)](/getting-started/setup/instance-management/upgrade-to-checkpoint-version) guide before you update to the latest release.
 - If your current version is later than v1.9.2 but earlier than v1.96, upgrade to a version between v1.96 and v1.99 before you upgrade to v2.0 or later.
:::

1. Find your Appsmith installation directory:
   ```bash
   docker inspect -f '{{ (index .Mounts 0).Source }}' <APPSMITH_CONTAINER_ID>
   ``` 
2. Choose the Appsmith version you want to run.

   Find its release tag on [GitHub](https://github.com/appsmithorg/appsmith/releases).

3. Open `docker-compose.yml` in that directory and set the `image` for the Appsmith service to a pinned tag, for example:

   ```yaml
   image: index.docker.io/appsmith/appsmith-ee:<version>
   ```

   If you use the Community Edition, replace `appsmith-ee` with `appsmith-ce` and keep the same `:<version>` suffix.

4. Pull the image and restart the container. The new container runs the version set in `docker-compose.yml`.

   ```bash
   docker-compose pull && docker-compose rm -fsv appsmith && docker-compose up -d
   ```

</TabItem>

<TabItem label="Kubernetes" value="kubernetes">

:::caution Important
If your current version is earlier than v1.9.2, follow the [Upgrade to Checkpoint Version (v1.9.2)](/getting-started/setup/instance-management/upgrade-to-checkpoint-version) guide before you update to the latest release.
:::

> **Note**: These instructions assume you followed the [Kubernetes installation guide](/getting-started/setup/installation-guides/kubernetes) exactly. If you changed any defaults, such as the Helm release name or namespace, adjust the commands to match.

1. Choose the latest Appsmith version.

   Find the latest release tag on [GitHub](https://github.com/appsmithorg/appsmith/releases).

2. Locate your Helm `values.yaml` file.
   - If you still have the `values.yaml` file from your initial installation, go to its directory:
     ```bash
     cd /path/to/your/values-file
     ```
   - If you no longer have the file, retrieve it from your cluster:
     ```bash
     helm get values appsmith-ee -n appsmith-ee | grep -v "USER-SUPPLIED" > values.yaml
     ```

3. Update the image tag in `values.yaml`.
   - If you have [`yq`](https://github.com/mikefarah/yq) installed:
     ```bash
     APPSMITH_VERSION=<version>
     yq -i ".image.tag = \"$APPSMITH_VERSION\"" values.yaml
     ```
   - If you don’t have `yq`, open `values.yaml` in a text editor and set the new version:
     ```yaml
     image:
       tag: <version>
     ```

4. Apply the upgrade with Helm.

   Run the following command:

   ```bash
   helm upgrade appsmith-ee -n appsmith-ee -f values.yaml
   ```

</TabItem>

<TabItem label="AWS ECS on EC2" value="aws-ecs-ec2">

1. Sign in to your AWS account and open the Amazon ECS console.
2. Select the cluster that contains the container instance you want to update.
3. Stop the task. ECS automatically deploys a new task.
4. Verify that the updated version is running.

</TabItem>

<TabItem label="Azure Container Instance" value="azure-ci">

1. In the Azure portal, find the Azure Container Instance that runs Appsmith.
2. Click **Restart** to restart the container.

</TabItem>

## Troubleshooting

If the update fails, roll back to the previous version by following the [Restore instance](/getting-started/setup/instance-management/backup-and-restore/restore-instance) guide. If the problem persists, contact support using the chat widget in the bottom-right corner of this page.
