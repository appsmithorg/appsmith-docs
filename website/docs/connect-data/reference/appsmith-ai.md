# Appsmith AI

:::caution Deprecated
The Appsmith AI datasource reached end of life on September 30, 2026, and is no longer available. You cannot create or run Appsmith AI datasources or queries.
:::

To add AI capabilities to your apps, use one of the following datasources instead:

- [OpenAI](/connect-data/reference/open-ai)
- [Anthropic](/connect-data/reference/anthropic)
- [Google AI](/connect-data/reference/google-ai)
